Repair passes

Each pass runs x12-tidy once. Pass 1 works on the interchange as submitted and does the structural repairs. Pass 2 (and any later pass) runs on the previous pass's output, so it shows only what is still wrong after those repairs. The loop stops when a pass changes nothing or finds nothing.

The Byte column is the offset into the submitted text where the flagged structure begins; ISA-line findings share a number, and a dash means the finding isn't tied to one spot.
