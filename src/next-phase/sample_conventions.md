# Sample interchanges — standard and distinct segments

Generated by `src/next-phase/identify_conventions.py` (issue #79). Not a shipped feature.

Standard shape: `sender-receiver-edinumber-edialpha-datesent` (ISA06-ISA08-ST01-GS08 convention letter-ISA09).

Segment reference-table key shape: `sender-receiver-release_version-segment_abbrev` — the next-phase parser checks one exists for every segment before translating.
